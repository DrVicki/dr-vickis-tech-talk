# Dr. Vicki's Excel AI Prompt Pack

This pack accompanies **Working with Excel Data Without Knowing a Single Formula** from Dr. Vicki's Tech Talk. It turns a familiar spreadsheet into a repeatable four-part review: **observe, verify, decide, and record**.

## Included templates

| File | Use it when |
|---|---|
| `01-spot-trends-and-assess-risk.txt` | You need a plain-language first read with an explicit confidence caveat. |
| `02-turn-findings-into-action.txt` | You need to convert a verified finding into an action, trade-off, and decision trigger. |
| `03-build-a-reusable-routine.txt` | You return to the same report and want consistent standing questions. |

## Recommended sequence

Begin with Prompt 1 and verify at least one important claim against the source cells. Use Prompt 2 only after the finding survives that check. Use Prompt 3 to save the questions worth repeating on the next update. Record the source period, assumptions, and approval in the companion Excel checklist.

> **Data safety:** Use an AI tool approved for the data you are handling. Do not upload confidential, regulated, personal, or client data to an unapproved service.
