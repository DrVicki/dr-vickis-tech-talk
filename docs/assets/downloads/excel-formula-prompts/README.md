# Dr. Vicki's Excel Formula Prompt Pack

This pack accompanies **How to Let AI Write Excel Formulas for You** from Dr. Vicki's Tech Talk. It treats an AI-generated formula as a draft that must be explained, stress-tested, and saved with its assumptions.

| File | Use it when |
|---|---|
| `01-translate-goal-to-formula.txt` | You know the result you want and need a compatible Excel formula plus an explanation. |
| `02-stress-test-edge-cases.txt` | The formula works on clean rows and needs to be tested against blanks, errors, duplicates, and mixed formats. |
| `03-build-reusable-formula-library.txt` | You want to save the reasoning and regenerate the formula for another workbook. |

## Recommended sequence

Describe the calculation and workbook layout with Prompt 1. Check the assumptions, then use Prompt 2 with the actual edge cases in your data. Use Prompt 3 only after the formula survives hand-checked test rows. Practice the sequence in the companion workbook before applying it to production data.

> **Data safety:** Use an AI tool approved for the data you are handling. Do not upload confidential, regulated, personal, or client data to an unapproved service.

The workbook datasets are fictional and provided solely for practice.
